# Shenlun Master — 申论备考训练 Skill

融合半月谈白鹭、B站小马哥（小题）和袁东（大作文）三位名师方法论，以申论命题人和阅卷人视角严格评判作答，提供子项级逐句评分和改进建议。

支持**文字与图片双输入**：试卷照片、题目截图、手写作答照片可直接发送，模型原生识读，无须预先转写文字或外接读图工具。

## 功能模块

### 错题库（长期能力追踪）
- **批改后自动记录**：每次批改把失分点按**类型**归入使用者本地的 `错题库/`
- **记类型，不记具体错误**：记的是"`B1-无统一句式`"这类可跨题比较的失分点类型，而不是"某题漏了某个采分点"——只有类型才能累积计数、看出复发模式
- **频次与状态**：🟡 初现（1 次）→ 🟠 复发（2 次）→ 🔴 顽固（≥3 次）
- **复发主动提醒**：同一失分点类型再次出现时，**主动提示"这是第 N 次"并指出上次在哪道题也犯过**；顽固项给**专项训练方案**
- **可查询**：问"我老毛病是什么""最近进步了吗"，按顽固→复发→初现排序输出，并明确指出已改善的项
- 分类体系（8 维度 · 细粒度编号）见 `references/error-bank-rules.md`；`错题库/` 已 gitignore，**个人数据不上传**

### 图片输入（原生支持）
- **直接用图片出题**：试卷照片、题目截图、材料扫描件、手写作答照片都可以直接发送，无须先转写成文字，也无须外接读图工具
- 图片识读规范：图片类型清点 → 结构化提取（题号/分值/字数/题干/材料）→ 模糊处标注自检 → 转写确认 → 无法识读时才降级
- **分值、字数限制、题号是评分基准**，识读时会主动向用户复核，读不准就标注 `[图像模糊]` 而不猜测
- 支持多图（多页试卷按页序拼接）、图文混合（冲突时以图片为准）、印刷体与手写体区分
- 兼容 DSH / Claude Code / Codex / Cursor 等环境，只要所选模型支持图像输入即可

### 真题识别
- 提交内容后**联网搜索 + 真题库双通道匹配**，自动定位考试年份、试卷类型、题号、原题
- 匹配成功后以真实阅卷采分点为评分基准，跳过通用推断
- 每次批改后自动入库，真题库渐进式扩充（`references/real-exams/`）

### 小题训练
- **归纳概括题**（含概括做法/问题/原因/经验/成效/变化/特点）：不写总括句，分条列要点，材料原词直抄
- **综合分析题**（词句理解/观点评析/现象分析/关系分析4子类）：总括句点题 + 分维度展开 + 回扣题干
- **公文写作题**：格式分+内容筛选（按文种目的取舍材料要点）+ 语言风格匹配
- 双视角参考作答：小马哥版（材料原词）+ 白鹭版（近义提炼轻串联）
- 默认精简格式输出，按需展开详细评分

### 大作文训练
- 袁东"三类型"主题判断（单主题/双主题AB型/双主题ABC型/多主题）
- 分论点关键词三步搜索法（题干→给定材料→前题材料）
- 阅卷人两轮评判（立意判定 + 多维细评）+ 创新加分机制
- 跑题给规范范文，不跑题给逐段优化版

### 命题预判
- 基于历年真题趋势（60%）+ 当年时政热点（40%）
- 支持国考（副省/地市/行政执法）、省考、事业单位

## 使用方式

安装此 Skill 到 Claude Code 后，直接用文字描述你的需求即可触发：

- "帮我批改这道申论对策题，我写了五点不知道有没有踩到采分点"
- "这道大作文题目是'守正与创新'，帮我看看有没有偏题"
- "我准备2026年国考地市级，帮我做命题预判"
- "这道综合分析题帮我分别从小马哥和白鹭的角度给参考答案"

也可以**直接发送图片**，例如：

- 拍一张整卷照片发过去 → 自动识读题干与材料，进入真题匹配
- 发一张手写作答照片 + "帮我批改第2题" → 识读作答内容后按采分点评分
- 逐题截图分多次发送 → 按题序拼接为完整试卷

> 图片识读依赖运行环境与所选模型支持图像输入。若当前环境/模型不支持，Skill 会明确告知并请你提供文字版本，不会假装读懂图片。

## 输出格式

**默认直接在对话中输出批改结果**，节省 token 开销。仅在用户要求「导出」「保存」「生成 word」时才生成 `.docx` 文件。

### Word 导出（按需）

依赖安装：
```bash
pip install python-docx
```

导出效果：参考作答区域浅蓝色底高亮，表格文字居中排版，序号独立不连号。

## 文件结构

```
shenlun-master/
├── SKILL.md                              # 核心工作流（常驻加载）
├── README.md
├── references/
│   ├── scoring-rules.md                  # 小题评分方法 + 精简/详细格式模板
│   ├── writing-rules.md                  # 作答铁律（7条）+ 版本差异
│   ├── expression-upgrade-rules.md       # 申论规范表述替换表 + 成语升级 + 名言金句
│   ├── fallback-eval-rules.md            # 无题干时通用文章评改（含卷面分）
│   ├── image-reading-rules.md            # 图片识读规范（6步流程 + 改进建议规范）
│   ├── error-bank-rules.md               # 错题库失分点分类表（8维度 · 复发提醒写法）
│   ├── bai-lu-methodology.md             # 白鹭方法论（含8类信号词完整表）
│   ├── xiaoma-methodology.md             # 小马哥方法论
│   ├── yuan-dong-methodology.md          # 袁东大作文方法论
│   ├── prediction-methodology.md         # 命题预判方法论
│   └── real-exams/                       # 真题知识库
│       ├── INDEX.md                      # 快速索引（关键词匹配）
│       ├── _TEMPLATE.md                  # 新真题添加模板
│       ├── 2022-fujian-shi.md            # 2022福建省市卷
│       ├── 2023-fujian-xianxiang.md      # 2023福建县乡卷
│       ├── 2023-sichuan-shi.md           # 2023四川省市卷
│       └── 2024-guangxi-A.md             # 2024广西A卷
├── scripts/
│   └── export_docx.py                    # md → docx 导出
├── _tools/                               # 名师原料提取工具（标准库，无依赖）
│   ├── docx_extract.py                   # .docx → 纯文本（保留段落与换行）
│   └── docx_media.py                     # .docx → 抽取 word/media 内嵌图片
└── _sources/                             # 名师原始资料（gitignore，含版权）
    └── 袁东/  白鹭/  小马哥/              # 讲义、笔记、真题答案原文与溯源分析

（运行时生成，已 gitignore）
错题库/                                    # 使用者个人错题库：INDEX.md + entries.md
```

> **关于 `_sources/`**：名师讲义、手写笔记、真题答案等原始资料含版权，**不进公开仓库**（已在 `.gitignore`）。
> 其中的**溯源分析**（哪条结论来自哪份原料）是这些文件得以重建的依据；如需复核结论来源，可自行准备同类资料后按 `_tools/` 的工具提取。
>
> **关于 `错题库/`**：记录使用者本人的失分点类型与频次，含个人作答与成绩，**同样不进公开仓库**，首次批改时自动创建。
