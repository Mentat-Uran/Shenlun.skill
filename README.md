# Shenlun Master — 申论备考训练 Skill

融合半月谈白鹭、B站小马哥和袁东三位名师方法论，以申论命题人和阅卷人视角严格评判你的作答，提供多维度评分和改进建议。

## 功能模块

### 小题训练
- **归纳概括题**：小马哥"问啥答啥+总括分类归并" + 白鹭"题干四要素+关键词阅读法"
- **对策启示题**：三来源框架（概括对策→借鉴对策→提出对策）
- **综合分析题**：白鹭 3W 十六字方针（中好坏策，有谁写谁）+ 小马哥灵活框架
- **公文写作题**：白鹭"五把钥匙"分层切入 + 小马哥格式速成法
- 双视角参考作答（小马哥版 + 白鹭版）+ 阅卷人三维度评分

### 大作文训练
- 袁东"三类型"主题判断（单主题/双主题AB型/双主题ABC型/多主题）
- 分论点关键词三步搜索法（题干→给定材料→前题材料）
- 阅卷人两轮评判（立意判定 + 多维细评）+ 创新加分机制
- 跑题给规范范文，不跑题给逐段优化版

### 命题预判
- 基于历年真题趋势（60%）+ 当年时政热点（40%）
- 支持国考（副省/地市/行政执法）、省考、事业单位

## 使用方式

安装此 Skill 到 Claude Code 后，直接用文字描述你的需求即可触发：

- "帮我批改这道申论对策题，我写了五点不知道有没有踩到采分点"
- "这道大作文题目是'守正与创新'，帮我看看有没有偏题"
- "我准备2026年国考地市级，帮我做命题预判"
- "这道综合分析题帮我分别从小马哥和白鹭的角度给参考答案"

## 输出格式

批改结果自动导出为 `.docx` 文件（使用 `scripts/export_docx.py`），参考作答区域有浅蓝色底高亮，表格文字居中排版。

### Word 导出依赖
```bash
pip install python-docx
```
