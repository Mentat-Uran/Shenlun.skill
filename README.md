# Shenlun Master — 申论备考训练 Skill

融合半月谈白鹭、B站小马哥（小题）和袁东（大作文）**有据可溯**的方法论，以申论命题人和阅卷人视角严格评判作答，提供子项级逐句评分和改进建议。

支持**文字与图片双输入**：试卷照片、题目截图、手写作答照片可直接发送，模型原生识读，无须预先转写文字或外接读图工具。

## 架构：三个 skill

拆成三个 skill 是为了**按需加载**——小题任务不必加载大作文的整套方法论，反之亦然。

| skill | 职责 | 加载成本 |
|---|---|---|
| **`shenlun-router`** | 总调度：图片/文字输入处理、真题识别、命题预判、错题库、**分派** | ~3.5k 字符 |
| **`shenlun-xiaoti`** | 小题：归纳概括／综合分析／对策／公文，双视角参考作答 | ~7k 字符（另按需读名师库） |
| **`shenlun-dawenti`** | 大作文：袁东体系、累进四类文评分、无题干兜底评改 | ~3k 字符（另按需读袁东库） |
| `skills/shared/` | 三者共用的规则与脚本（图片识读、表述升级、错题库、导出） | 不单独加载 |

**一个小题任务的典型加载**：router(~3.5k) + xiaoti(~3k) + 白鹭库(~6.6k) 或小马哥库(~6.2k) + 评分规则(~1.7k) ≈ **15k 字符**
**一个大作文任务**：router + dawenti + 袁东库(~10k) ≈ **16k 字符**
—— 两条路径互不加载对方的材料。

### 安装（任意支持 skills 的 agent）

本仓库不绑定任何特定 agent。**只要该 agent 支持"技能目录"机制，把三个 skill 挂进去即可。**

三个 skill 必须各自作为技能目录的**直接子目录**（技能扫描只认 `<root>/<name>/SKILL.md`，**不递归**）。
仓库已在 `skills/` 下备好三个目录，建三个链接指向它们：

```powershell
# 把 <技能目录> 换成你所用 agent 的技能根目录（见下表）
$root = "<技能目录>"
$repo = "<本仓库路径>"
foreach ($n in @("shenlun-router","shenlun-xiaoti","shenlun-dawenti")) {
  New-Item -ItemType Junction -Path "$root\$n" -Target "$repo\skills\$n"
}
```

**常见 agent 的技能根目录**：

| agent | 技能根目录 | 依据 |
|---|---|---|
| DSH | `~/.dsh/skills`（用户级）或 `<项目>/.dsh/skills`（项目级） | ✅ 已核实（源码 + 本机实测） |
| Claude Code | `~/.claude/skills` | ✅ 已核实（本机实测） |
| 通用 agents 约定 | `~/.agents/skills` | ✅ 已核实（本机实测） |
| 其他 agent | 见其文档中"skills"配置项 | ⚠️ 未逐一验证 |

> ⚠️ **仅上表末行"其他 agent"未经核实**，请以你所用 agent 的文档为准（前三行已核实）。
> 判断标准很简单：**该 agent 是否扫描某个目录下单层子目录里的 `SKILL.md`**——是，就能装。

> Windows 建**符号链接**需要管理员权限，**目录联接（Junction）不需要**，效果相同——故上面用 `Junction`。
> macOS / Linux 把 `New-Item -ItemType Junction` 换成 `ln -s "$repo/skills/$n" "$root/$n"` 即可。
>
> 也可不用链接，直接把 `skills/` 下三个目录复制到技能目录——代价是仓库更新后需重新复制。

## 功能模块

### 错题库（长期能力追踪）
- **批改后自动记录**：每次批改把失分点按**类型**归入使用者本地的 `错题库/`
- **记类型，不记具体错误**：记的是"`B1-无统一句式`"这类可跨题比较的失分点类型，而不是"某题漏了某个采分点"——只有类型才能累积计数、看出复发模式
- **频次与状态**：🟡 初现（1 次）→ 🟠 复发（2 次）→ 🔴 顽固（≥3 次）
- **复发主动提醒**：同一失分点类型再次出现时，**主动提示"这是第 N 次"并指出上次在哪道题也犯过**；顽固项给**专项训练方案**
- **可查询**：问"我老毛病是什么""最近进步了吗"，按顽固→复发→初现排序输出，并明确指出已改善的项
- 分类体系（8 维度 · 细粒度编号）见 `skills/shared/references/error-bank-rules.md`；`错题库/` 已 gitignore，**个人数据不上传**

### 图片输入（原生支持）
- **直接用图片出题**：试卷照片、题目截图、材料扫描件、手写作答照片都可以直接发送，无须先转写成文字，也无须外接读图工具
- 图片识读规范：图片类型清点 → 结构化提取（题号/分值/字数/题干/材料）→ 模糊处标注自检 → 转写确认 → 无法识读时才降级
- **分值、字数限制、题号是评分基准**，识读时会主动向用户复核，读不准就标注 `[图像模糊]` 而不猜测
- 支持多图（多页试卷按页序拼接）、图文混合（冲突时以图片为准）、印刷体与手写体区分
- 只要所用 agent 与所选模型**支持图像输入**即可使用，不依赖任何外部读图工具或 MCP

### 真题识别
- 提交内容后**联网搜索 + 真题库双通道匹配**，自动定位考试年份、试卷类型、题号、原题
- 匹配成功后以真实阅卷采分点为评分基准，跳过通用推断
- 每次批改后自动入库，真题库渐进式扩充（`skills/shenlun-xiaoti/references/real-exams/`）

### 小题训练（`shenlun-xiaoti`）
- **双视角参考作答**，且**两版结构性不同**（不是换措辞）：
  - **小马哥版**：结构固定、要素融合——一律「上位概括词 + 具体做法」
  - **白鹭版**：结构随题干、要素分栏——题干有几个要素/对象/主体就分几栏（问"变化"用过去/现在对比；问"举措及成效"则配对）
- **差异对照五项**：各自多踩/漏了哪个采分点、分类逻辑差异、各自适用场景、各自风险、**"你更适合哪一套"**
- **诚实边界**：某些环节两版其实一致（如总括句有无、概括词需统一句式）会**直说"此处两版一致"**，不凑对照
- 评分 = 采分点覆盖法（子项逐条核对），使用题目实际分值

### 大作文训练（`shenlun-dawenti`）
- **第一原则：文无定式**——公式只是"想不出怎么写时的备用工具"，有更好的衔接就用更好的，**不因偏离公式扣分**
- **袁东累进四类文**：跑题→三类→（开头结尾写得好）二类→（分论点论证写得好）一类
- **强制第一动作**：判单/双/多主题 → 双主题再判 **AB 型／ABC 型** → 按对应模板逐段核对
  （ABC 型 = A、B 共同作用于大目标 C，如"现代与传统"→社会文明）
- **禁止**用"分分总/总分总"等通用文章学术语下判语——曾因此把 ABC 型的第三层误判为"总结段"
- 模板档／进阶档两层；无题干时转通用文章评改模式（含**卷面分**）

### 命题预判
- 基于历年真题趋势（60%）+ 当年时政热点（40%）
- 支持国考（副省/地市/行政执法）、省考、事业单位

## 使用方式

**把三个 skill 安装到任意支持 skills 的 agent 上（DSH / Claude Code / Codex / Cursor 等，安装见上文「安装」），
之后直接用自然语言描述需求即可触发。**

### 三条使用路径

**① 提交作答要批改**（最常用）——发题干（或说"哪年哪场第几题"）+ 你的作答：

- "帮我批改这道申论对策题，我写了五点不知道有没有踩到采分点"
- "这道大作文题目是'守正与创新'，帮我看看有没有偏题"

**② 只要参考答案，不提交作答**——给出题目即可，会输出双视角参考作答与采分点：

- "这道综合分析题帮我分别从小马哥和白鹭的角度给参考答案"

**③ 问方法与查短板**——不涉及具体题目时：

- "我准备2026年国考地市级，帮我做命题预判"
- "我的老毛病是什么""最近进步了吗" → 读错题库给诊断

### 它会自动分派

你不需要指定用哪个 skill，路由器会按题目类型分派：

| 你的问题 | 实际由谁处理 |
|---|---|
| 概括题／分析题／对策题／公文题 | `shenlun-xiaoti` |
| 大作文／议论文 | `shenlun-dawenti` |
| 命题预测／查错题库／发图片 | `shenlun-router` |

**判不准时它会问你一句**"这是小题还是大作文"，不会猜。

### 也支持直接发图片

- 拍一张整卷照片发过去 → 自动识读题干与材料，进入真题匹配
- 发一张手写作答照片 + "帮我批改第2题" → 识读作答内容后按采分点评分
- 逐题截图分多次发送 → 按题序拼接为完整试卷

> 图片识读依赖运行环境与所选模型支持图像输入。若当前环境/模型不支持，Skill 会明确告知并请你提供文字版本，不会假装读懂图片。

### 一次批改你会拿到什么

以小题为例（大作文结构类似，但改为袁东四类文评分）：

```
你：帮我批改这道归纳概括题（附题干与作答）

① 真题识别结果      试卷 / 题号 / 题型 / 分值 / 原题
② 参考作答·小马哥版  结构固定、要素融合：概括词 + 具体做法
③ 参考作答·白鹭版    结构随题干、要素分栏（与上一版【结构性不同】，不是换措辞）
④ 差异对照          各自多踩/漏了哪个采分点 · 分类逻辑差异 · 各自适用场景 ·
                    各自风险 · 落点"你更适合哪一套"
⑤ 阅卷人评判        采分点逐条核对 + 总分（用题目实际分值，非百分制）
⑥ 改进建议          必须补的失分点 → 表述升级 → 成语与名言可用之处 →
                    论证思路怎么改 → 优化示范（五段式，只给怎么改，不做诊断）
⑦ 复发提醒          若某失分点类型已出现 ≥2 次，指出"这是第 N 次"及上次在哪道题
```

> **若某环节两版其实一致**（如总括句有无、概括词需统一句式），会**直说"此处两版一致"**——
> 不为了凑对照而编造差异。

### 错题库

**你不需要做任何操作**——每次批改后自动记录到工作区的 `错题库/`（首次批改时自动创建）。

- **查短板**：直接问"我的短板在哪""最近进步了吗"
- **隐私**：`错题库/` 已加入 `.gitignore`，**个人作答与成绩不会上传公开仓库**
- **细节**（记什么、状态分级、复发提醒、撤销机制）见上文 [错题库（长期能力追踪）](#错题库长期能力追踪)

## 输出格式

**默认直接在对话中输出批改结果**，节省 token 开销。仅在用户要求「导出」「保存」「生成 word」时才生成 `.docx` 文件。

### Word 导出（按需）

依赖安装：
```bash
pip install python-docx
```

导出效果：参考作答区域浅蓝色底高亮，表格文字居中排版，序号独立不连号。

>
