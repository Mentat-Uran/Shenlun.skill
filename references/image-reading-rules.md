# 图片识读规范

用户可直接发送试卷照片、题目截图、材料扫描件、手写作答照片。模型原生识读，**不要要求用户先转写成文字**。

**核心原则：先完整转写，再进入分析。** 读图不准会污染后续所有环节（真题匹配、审题、采分点、评分），所以读图必须先于一切判断。

## Step 1：判断图片类型并逐张清点

- **整卷照片**：含多道题的题干与材料。先通读全图，建立"有几则材料、有几道题"的整体认知，再逐题提取。
- **单题截图**：只含某一题的题干与要求。仍需留意截图边缘可能被裁掉的"要求"条款。
- **材料页**：只有给定资料、没有题干。需确认对应的是第几则材料。
- **作答页**：用户手写或打字的答卷，需识别题号与作答内容的分界。

多张图片时，**先说明你识别到的图片顺序与各自内容**，让用户有机会纠正页序错误。

## Step 2：结构化提取

对每个图片，按以下结构转写，缺一不可：

1. **题号与题型标记**——"第X题""（X分）"
2. **题干原文**——逐字转写，含引号内引文
3. **要求条款**——字数限制（"不超过300字"）、条理要求、作答范围（"根据给定资料2"）
4. **给定材料**——按则编号，材料内的关键数据、案例名、地名、人名
5. **分值**——这是评分基准，必须准确

**字数限制与分值是最关键的字段**，读错会直接导致答案长度和评分基准错误。如果模糊不清，宁可向用户确认，不要猜。

## Step 3：自检与纠错

- **扫描件/翻拍照片**：可能有阴影、倾斜、反光。若某处字迹模糊，明确标注 `[此处图像模糊]`，而不是凭上下文编造。
- **易混字**：申论材料中的专有名词（地名、政策名、机构名）容易识错，如"背篓"与"背蒌"、"信托"与"信贷"。原则：**只转写你确实看清的字**，不确定的标注出来。
- **手写作答**：用户字迹潦草时，拼读出可能的词语并请用户确认，尤其是数字和关键术语。
- **表格/图表**：如有数据表，转写为文字描述并保留具体数值。

## Step 4：输出转写结果并请用户确认

在正式分析前，先给出一份简短转写摘要：

```
## 图片识读结果
- **图片数量**：X 张
- **识别到的试卷**：{考试全称或"未知"}
- **题目**：第{X}题（{题型}，{分值}分）
- **题干**：{转写原文}
- **要求**：{字数与条理要求}
- **材料**：{第X则，概要}

请确认以上识读是否准确，特别是**字数限制和分值**。如有出入请指出，我再据此分析。
```

用户确认后（或用户未提出异议时）继续进入真题识别流程。

## Step 5：无法识读时的降级路径

仅当图片确实无法读取时才降级，**不要一遇到图片就降级**：

| 情况 | 处理方式 |
|------|---------|
| 图片未成功传入 / 路径不可读 | 说明情况，请用户重新发送图片，或提供图片的可访问路径 |
| 图片严重模糊、内容无法辨认 | 指出具体哪一部分看不清，请用户针对该部分补充文字 |
| 手写作答字迹完全无法辨认 | 请用户把作答内容打成文字发给你，同时说明题目部分你已读出 |
| 当前环境确实无法读图 | 坦诚说明，请用户提供题目与作答的文字版本，并说明其所在环境需要支持图像的模型 |

> **环境说明**：读图能力取决于运行环境与所选模型是否支持图像输入。若确实无法读取图片，应直接告知用户"当前环境/模型不支持图像输入，请改用支持图像的模型或提供文字版本"，**而不要假装读懂了图片内容**。

## Step 6：「语言错误清单」输出规范

批改手写作答时，最容易犯的错不是读不出字，而是**把自己读不准的字当成用户写错的字**。以下为强制规范。

### 6.1 绝对禁止：编造错字

**只在你确实看清了字形，且确认写错时，才列该字为错误。**

如果你没看清原文却填了一个"错字"进去，那不是批改，是**把你自己的臆测栽给用户**。

### 6.2 逐字自检：先筛再扣

你要区分三个问题，**不要把第二个当成第一个**：

1. 你**找**这个字时，它找到的是对的吗？（对应你心里的正确写法）
2. 你**看**这个字时，看到的是错的吗？ ← 只有这一项能支撑"错别字"结论
3. 你是否**没看清**，却凭上下文默认它错了？

**自检动作**：对每一个准备列出"错误"的字，问一句——
> **"用户写的那个字形，我真的看清了吗？"**

没看清 → 标 `[字形不清]` 或直接不列，**绝不编造**。

### 6.3 禁止无效对照：左右两栏必须不同

表格里 `原文` 与 `应改为` **必须真实不同**。

如果两者相同（如"仍→仍"、"召→召"），说明**你其实没找到错**，只是把正确写法填了两遍。这是逻辑上不可能成立的"修改"，比不写更糟——它会让用户怀疑你根本没看图。

**发现左右相同时的处理**：不要删掉了事，改成一句正面陈述：
> "此处我核对的是『仍』，写法正确。"

这既诚实，又让用户知道你检查过。

### 6.4 认字不确定时的写法

| 情况 | 写法 |
|------|------|
| 看清写错了 | `原文` 写你看到的字形，`应改为` 写正确写法 |
| 疑似写错但不确定 | `原文` 写 `[字形不清：疑为"X"]`，问题栏写"疑似字形，请确认" |
| 看清是对的 | 不出现在错误清单里；必要时单独说明"已核对无误" |
| 完全看不清 | `[图像模糊]`，不猜、不列 |

### 6.5 优先报搭配与语法，而非笔画

**同一处错误，先问它是"搭配/语法"问题还是"字形"问题。**

搭配与语法问题（如"党委是共同富裕的长期性对未来做部署"缺主语、"但"前后非转折）**不依赖辨字**，判对率远高于逐字挑错别字，也更能提分。

因此：**语言问题清单以搭配、语序、关联词、成分残缺为主，字形错误为辅。**

### 6.6 手写笔误的严重性尺度

**不要因为一篇作文里有几处笔误就重扣语言分。**

- 1000-1200 字的大作文出现几处笔误属正常，**不影响阅读与理解就不构成"语言表达差"**
- 只有**语法断裂、关联词误用、成分残缺、搭配不当**这类问题密集出现，才真正反映语言基本功
- 判断标准是**是否影响语义传达**，不是**错字计数**

> **越界警示**：如果你发现自己写出的错别字表里，有任何一行是"X→X"（左右同一个字），说明你在猜字。立即停下来，把该行改为正面核对陈述或标 `[字形不清]`。
