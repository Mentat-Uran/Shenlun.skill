# 评分方法与输出格式

## 一、评分方法：采分点覆盖法（子项逐条核对）

### Step 0：列出子项级采分点清单

基于完整给定材料，将每个采分点拆为可逐条核对的子项，每个子项明确分值。所有子项分值之和 = 题目总分值。

子项拆分原则：材料中每个与题干直接相关的关键词 / 短语 → 一个子项。同一语义群内的细节可合并，不同语义群必须分开。

> 已匹配到真题时直接使用真题详情中的子项级采分点。

### Step 0.5：先做材料逻辑与要素复核（袁东层）

在给分前，先检查答案底稿是否把材料读对：

1. **宏观**：段首、段尾、高频词、关联词、关键词、主体；
2. **中观**：总分 / 分总 / 总分总 / 并列 / 递进；
3. **微观**：把信息化大为小，并只保留与题干目标有关的内容；
4. **原词优先**：关键动词、对象、结果词尽量保留材料原词原意；
5. **案例处理**：故事案例通常提炼后跳过，除非题干明确要求案例、表现或需要从案例提炼启示。

> 这一层是“找点与复核”，不是独立扣分表。只有它最终导致漏采分点、答非所问、格式错误或字数浪费时，才反映到分数。

### Step 1：逐条核对用户作答

对每个子项判断：踩到（≥80%，满分）、部分踩到（40-80%，一半）、未踩到（<40%，0分）。

**逐句勾划标记**：
- 无标记 = 踩到给分
- ~~删除线~~ = 材料无此内容 → 不得分
- **【缺：xxx】** = 遗漏关键词
- △ = 表述不准
- ✗ = 严重错误

### Step 2：输出结果

默认用精简格式，用户说“展开”/“详细”/“逐句展开”才切换详细格式。

### Step 3：汇总得分

申论踩点加分制——踩到给分，没踩到不给。不存在倒扣。

**编造内容**：该项不得分，不额外倒扣。编造的成本是占字数挤占踩点空间。

**口语化 / 表述不准**：不单独扣分。如果导致命中不了采分点关键词，该项不得分——失分体现在采分点覆盖率上。

**教师模板**：不属于采分点。用户没有按某位老师的固定写法组织答案，不得据此扣分。

### Step 4：生成满分答案

满分答案先过四层检查：

1. **题干完整回应**：题干问几个对象 / 要素，就覆盖几个；
2. **材料忠实**：答案主体以材料原词原意为主，关键动词、对象、结果词优先保留；
3. **逻辑正确**：优先尊重材料总分、并列、递进等关系，不为了“凑三点”硬拆；
4. **字数有效**：尽量把字数用于采分点，不写无得分价值的套话。

具体规则：

- 字数以题目上限为硬约束；无需机械追求固定比例，通常写到足以覆盖全部采分点即可；
- **不是“100%照抄原词”**：袁东 PDF 强调答案主体大量使用原词原句（提纲表述为“70%以上”），执行时理解为“原词原意优先”，不机械统计字符比例；
- 概括词优先选材料里的“大词 / 上位词 / 总结词”，必要时可用材料已有词重新组合，但不得凭空增加材料没有的含义；
- 归纳概括题是否写总括句，按已验证题型规则与题干实际需要处理；
- 综合分析题先完成对题干对象的解释 / 总括，再按材料补表现、原因、影响、问题、对策等要素；
- 原因题候选点必须能通过“代入法”；
- 对策题按“直接对策 → 问题反推 → 案例启示 → 知识储备兜底”找点；
- 公文题先满足题干指定内容，再核对文种格式；不得为了格式完整擅自添加题干未要求的部分；
- 附带采分点自检清单。

### Step 5：参考答案对照

默认至少生成并检查：

- **小马哥版**：结构稳定、概括词 + 具体内容；
- **白鹭版**：结构随题干、多要素分栏 / 分层。

两版都要经过**袁东材料复核**：材料逻辑、原词、要素、公文文种。

仅在以下情况增加**袁东版**：

- 用户明确要求；
- 用户要求三位老师对照；
- 公文题存在袁东 PDF 中明确的独立文种结构；
- 袁东组织方式与另两版存在实质差异。

对照时说明哪一版**更完整覆盖本题采分点、哪一版更省字、哪一版结构更贴合题干**；不要因为“像某老师”而加分。

## 二、什么不算扣分点

- **没有照某位老师模板**：不扣分。只看采分点、题干回应、逻辑和必要格式。
- **不写总括句（归纳概括题）**：若题干与采分点并不要求，不单独扣分；综合分析题若缺少必要解释 / 总括，按实际影响处理。
- **不写具体地名 / 主体名**：除非题干明确要求，否则泛化表述踩到方向即给分。
- **要点排列顺序**：普通按点给分题中，顺序通常不独立扣分；但若题干要求“变化前后”“原因—结果”“问题—建议对应”等逻辑关系，顺序会影响条理与可读性。
- **问题与建议分开列 vs 配对列**：不机械扣分。以题干要求、材料结构和是否便于阅卷识别为准。
- **没有使用“高级词”**：不扣分。保留材料关键词比自造高级表达更重要。

## 三、公文专项评分检查

公文题除采分点外，再检查四层：

1. **任务内容**：题干要求的成效 / 问题 / 建议 / 工作事项等是否全部完成；
2. **文种目的**：宣传、汇报、建议、简讯、短评等是否选对材料内容；
3. **必要格式**：标题、称谓、落款、日期等是否该有的有、不该有的不硬加；
4. **结构完整**：开头、主体、结尾是否围绕任务服务，而非机械套模板。

遇到发言提纲、宣传稿、汇报提纲、调研报告、工作建议、短评、简讯、工作内容、内容提纲、实用建议 / 提案、编者按、工作简报、案例摘要时，读取 `yuan-dong-xiaoti-methodology.md` 的对应专项规则复核。

| 3 | [原文句] | △ | 漏关键词“XX” |

### 总分：X / XX

### 主要失分
- **缺“XX”采分点**（-X分）
- **XX要素答成YY**（影响X分）
