# 小题作答铁律与版本差异

## 一、作答铁律（8条）

### 1. 字数铁律

- 题目字数上限是硬约束；
- 不机械追求固定“85%-95%”，以**覆盖采分点后尽量紧凑**为准；
- 单条要点过长时优先拆语义层，不为凑字数写套话。

### 2. 句子结构铁律

每条优先写成：**核心概括 / 动词短语 + 具体对象 + 必要结果 / 目的**。

- 对策题尤其强调“**动词 + 事情**”；
- 问题、原因、影响题不能强行套成动词句，要服从题干要素。

示例：

- 差：政府应该加大对停车设施的财政投入力度；
- 好：将停车设施建设纳入城市更新专项资金，重点投向老旧小区改造。

### 3. 去水铁律

删除不贡献采分点的套话，例如：

- “在……的过程中”；
- “高度重视”；
- “充分认识”；
- “进一步加大力度”；
- 无实际内容的“借鉴XX经验 / 参考XX模式”。

但公文开头、结尾是否保留，要看**文种与题干任务**，不能把所有背景句、过渡句一律视为废话。

### 4. 概括词铁律：材料优先，不机械“零自拟”

**核心不是“材料里必须逐字出现这个四字词”，而是不能改掉材料原意。**

优先级：

1. 材料已有上位词 / 总结词 / “大词” → 直接用；
2. 材料没有现成上位词 → 可把材料已有词进行轻度组合 / 压缩；
3. 只有在不增加材料外含义的前提下，才允许必要的规范提炼。

自检三问：

- 材料是否支持这个概括？
- 概括后有没有丢掉关键动词、对象、结果词？
- 这个词只是“更高级”，还是确实能帮助阅卷人快速识别采分点？

> 袁东 PDF 的口径是：答案主体大量使用原词原句（提纲表述“70%以上”）。执行时理解为**原词原意优先**，不要机械计算比例，也不要把它误写成“100%不得改写”。

### 5. 材料逻辑铁律

在合并要点前，先看材料的：

- 总分；
- 分总；
- 总分总；
- 并列；
- 递进。

**优先材料逻辑，不先凑“三点 / 四点”。**

同一个主题 / 话题的若干段可以作为一组；不同语义群不能为了减少条数硬并。

### 6. 题型要素铁律

- **问题**：找负面、消极、坏的信息；
- **原因**：候选点用“之所以……是因为……”做代入检验；
- **对策**：直接对策 → 问题反推 → 案例启示 → 知识储备兜底；
- **词句理解**：先就近解释，再补材料中的表现 / 原因 / 影响 / 问题 / 对策；
- **变化分析**：按“变化前 / 变化后 + 变化方面”组织，不能只写一端。

### 7. 公文题干优先铁律

**题干最大，模板第二。**

- 题干只让写“工作事项 + 工作内容” → 只写主体；
- 题干只让写“案由 + 建议” → 不额外补无关格式；
- 题干让写“成效 + 问题 + 建议” → 主体就按这三层展开；
- 标题、称谓、落款、结尾是否出现，按文种与场景决定。

袁东 13 类公文专项见 `./yuan-dong-xiaoti-methodology.md`。

### 8. 每句自检

写完答案逐句问：

1. 这一句回答的是题干要求的要素吗？
2. 这一句能对应材料依据吗？
3. 这一句包含可识别的采分关键词吗？
4. 删除这一句会不会丢分？

若四问都不能给出明确理由，就删或改。

## 二、三种方法的差异定位

| | 小马哥 | 白鹭 | 袁东 |
|---|---|---|---|
| 核心用途 | 稳定成文 | 题干拆解 / 灵活分层 | 找点 / 材料逻辑 / 文种复核 |
| 概括词 | 偏直接使用材料上位词 | 可做轻度前置提炼 | “选大词 + 选词组合”，原词原意优先 |
| 结构 | 上位概括词 + 具体内容 | 随题干要素 / 主体变化 | 宏观—中观—微观扫描后再组织 |
| 公文 | 格式对 + 要点齐 | 按题干层次筛材料 | 六要素 + 13 类常见文种专项 |

### 默认组合方式

1. 袁东先做材料扫描、逻辑分组、要素定位；
2. 白鹭检查题干到底要分几栏、按什么顺序；
3. 小马哥把要点压成答题卡上稳定、清楚、可识别的句子；
4. 再用袁东复核原词、材料逻辑、公文文种。

## 三、材料分析信号词

**白鹭完整信号词表**见 `./bai-lu-methodology.md` 第二节；
**袁东底层扫描**见 `./yuan-dong-xiaoti-methodology.md` 第一节。

合并速记：

- **先看位置**：段首、段尾；
- **再看信号**：高频、关联、关键词、最高级、转折、递进、并列、结论、权威观点、特殊符号；
- **再看主体**：谁做、谁说、谁受影响；
- **再看大逻辑**：总分 / 分总 / 总分总 / 并列 / 递进；
- **最后微观拆点**：化大为小，只保留与题干目标直接相关的信息。
