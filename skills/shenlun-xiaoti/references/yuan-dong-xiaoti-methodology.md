# 袁东（小题 / 公文）方法论

> **来源说明**：本文件依据用户提供的 5 页《袁东申论》可打印文字版整理，只记录 PDF 中明确出现的讲法，并将其转化为可供 skill 执行的步骤。
>
> **使用边界**：这份 PDF 是高度压缩的思维导图/提纲，不是完整课程逐字稿。凡 PDF 没有说明的阅卷扣分、固定分值、适用范围，不得自行补成“袁东明确规定”。
>
> **定位**：袁东在小题部分最有价值的不是再造一套“答案长相”，而是补强三件事：
> 1. **读材料的底层扫描顺序**（宏观—中观—微观）；
> 2. **按题型识别要素、从材料定位答案**；
> 3. **公文写作的文种化处理**（六要素 + 13 类常见文种）。
>
> 因此，本库默认作为小马哥 / 白鹭作答前的**找点与复核层**；只有当袁东对某类题给出独立结构（尤其公文）时，才需要单独生成“袁东版”。

## 一、申论之根：三层读材法

### 1. 宏观：粗读

粗读优先看：

1. **段首、段尾**；
2. **高频词、关联词、关键词**；
3. **主体**（谁在做、谁受影响、谁提出观点）。

目的不是立刻抄答案，而是先判断：这一段大致讲什么、与题干哪个要素有关。

### 2. 中观：五种大逻辑

识别材料段落之间的关系：

1. **总分**；
2. **分总**；
3. **总分总**；
4. **并列**；
5. **递进**。

并据此做**段落划分**：围绕同一个主题 / 话题的若干段，视为一个信息组。

> **执行规则**：优先尊重材料自己的组织逻辑。不要先想“我要分三点”，再硬把材料塞进三个筐。

### 3. 微观：精读

精读做两件事：

- **化大为小**：把大段信息拆成最小可得分语义单元；
- **目标导向**：始终用题干要求过滤材料，只精读与作答对象有关的部分。

### 4. 总括 / 提炼

袁东的提纲给出三层动作：

- 宏观：粗读，抓首尾、高频；
- 中观：看五种大逻辑；
- 微观：**选“大词” + 选词组合**。

这里的“大词”优先来自材料中的上位词、总结词、概括性表达；必要时可把材料已有词重新组合成更紧凑的概括语，但不能把材料没有的含义凭空造出来。

### 5. 材料忠实度四条

- **优先材料逻辑**；
- **故事案例通常跳过**（除非题干明确要求案例、事例、表现或需要用案例提炼启示）；
- **规范性表达优先原词原句**；
- PDF 明示“**70% 以上都是写原词原句**”——执行时理解为“答案主体以材料原词原意为主”，不要机械计算字符比例。

## 二、概括题：先把“要素”找准

### 1. 概括对策 / 做法

**找：动词 + 事情。**

例如不是只写“培训”，而是尽量保留“开展什么培训 / 面向谁培训 / 为了解决什么”。

### 2. 概括问题

找材料中**负面的、消极的、坏的**信息。

执行时优先保留：问题对象 + 问题状态 / 表现；若字数允许，再保留造成的直接后果。

### 3. 概括原因

PDF 提示：原因可能藏在“因为—所以”关系中，也可能出现在对策、影响等信息之前。

核心工具：**代入法**——把候选句代入题干：

> “之所以出现题干所述现象，是因为 ______。”

语义能成立，且材料支持，才算原因。

### 4. 概括作用 / 影响

围绕“产生了什么结果 / 改变了什么 / 对谁有什么作用”找点；材料有明确结果词时优先保留原词。

### 5. 观点类要求

若题目要求“观点鲜明 / 观点正确”，需在答案中给出明确立场：

- 支持；
- 反对；
- 辩证看待。

立场本身仍尽量用材料已有评价或判断表达，不为“有态度”而制造材料外观点。

### 6. 综合概括

继续使用**代入法**：每个候选要点都代回题干，看它是否真正回答题干所问，而不是“材料里看起来重要就写”。

### 7. “双性词”提醒

PDF 提到有些词既可表达**对策**，也可表达**影响 / 结果**。因此不能只看词面，要放回句子判断它在当前语境中的功能。

## 三、分析题

### 1. 启示分析

核心仍是找**可转化为行动的做法**，即“动词 + 事情”。

从案例提炼时，不抄具体地名、人名和偶然细节，而抽出可迁移做法。

### 2. 词句理解

#### 第一步：就近原则

先找划线词句**前后文**有没有直接解释、同义改写、因果说明或例证后的总结。

#### 第二步：改写开头

从材料中选一个更准确的**概括词 / 上位词**，把它放到答案开头，对词句含义先做一句解释。

#### 第三步：补“内容 + 要素”

材料有什么写什么，常见要素包括：

- 表现；
- 对策；
- 影响；
- 原因；
- 问题。

#### 第四步：总结

**材料有合适总结就写；没有就不硬编。**

### 3. 变化分析

先做方向预判：

- **变化前**通常是坏的、消极的、负面状态；
- **变化后**通常是改善后的正面状态。

再用常识做初步预判，但最终必须回到材料：粗读每段是在写“变化前”还是“变化后”、写的是哪方面变化，再据此分组。

> 常识只能帮助定位，不能代替材料作答。

## 四、对策题

### 1. 单一对策题：四级来源

按优先级找：

1. **材料直接给对策** → 摘抄 / 轻改写；
2. **材料给问题** → 反推对策；
3. **成功 / 失败案例** → 提炼可迁移启示；
4. **自身知识储备补充** → 仅在题干允许、材料不足且补充内容与材料方向一致时使用。

> 第 4 级是兜底，不得用常识覆盖材料，更不得为了“显得专业”补一堆材料没有依据的政策术语。

### 2. 复合对策题

若题干同时要求问题与建议，按“两段式 / 两栏式”处理：

- **问题：** 1… 2… 3…
- **建议：** 1… 2… 3…

能一一对应时尽量对应；材料本身并非一一对应时，不强造配对。

## 五、公文写作：六大要素

### 1. 标题

两种常用方式：

- **规范式**：关于 + 主题 + 的 + 文种；
- **个性式**：对策 + 影响（适合宣传、短评等允许个性化标题的文种）。

### 2. 称谓

结合题干和材料确定对象，例如“各位领导”“广大居民”等；题干未要求、文种不需要时不要机械添加。

### 3. 开头

可从材料中选：

- 目的；
- 背景；
- 意义；
- 问题；
- 成绩；
- 对策；
- 过渡句。

通常优先从材料前部找。只写与文种目的有关的，不是七项都写。

### 4. 主体

PDF 明示：公文主体大多数围绕**对策 + 影响**，一般集中在材料中部。

但最终仍以题干为最高指令：题干让写经验就写经验，让写成效 / 问题 / 建议就按要求分层。

### 5. 结尾

常见功能：期待、呼应、展望、号召、总结。

- 材料有合适结尾 → 使用；
- 材料没有、文种也不强制 → 不硬写；
- 对短评等需要完整收束的文种，可自行补一句简短收束。

### 6. 落款

需要时写“单位 + 日期”，一般置于右下角；特殊文种按文种规则处理。

## 六、13 类公文 / 应用文专项

> **总原则：题干最大。** 文种模板只负责提醒“哪些部件通常要有”，不能压过题干具体任务。

### 1. 发言提纲

- 标题：关于 + 会议 / 主题 + 的发言提纲；
- 开头：简述背景 / 目的，并用“经验如下 / 情况如下”过渡；
- 主体：以做法 / 对策为主，分点展开；
- 结尾：材料有则写，无则可省。

### 2. 宣传稿

- 标题可个性化；
- 开头交代事件 / 背景 / 成效；
- **通常不用单独写过渡段**；
- 主体按题干写“对策 / 影响 / 对策 + 影响”；
- 结尾可作推广、展望或号召。

### 3. 汇报提纲

- 标题：关于 + 工作主题 + 的提纲；
- 开头：“……思路 / 情况如下”；
- 主体适合“大点 + 小点”的层级结构：一、…… 1.…… 2.……；二、……；
- 结尾可用“汇报完毕”等简短收束，是否写看题干场景。

### 4. 调研报告

- 开头：“……情况如下”；
- 主体通常是**问题 + 对策**；
- 问题与建议有明确对应关系时尽量一一对应；
- 材料没有结尾可不写。

### 5. 工作建议

- 开头简述事件 / 背景，接“提出如下建议”；
- 主体：纯对策，推荐“小标题 + 具体内容”；
- 结尾可用“以上建议供参考”等简短语。

### 6. 短评

- 标题宜“对策 + 影响”或能体现鲜明观点；
- **不单写过渡句**；
- 主体：概括对策（动词 + 事情）+ 影响，可用若干总括词展开；
- 即使材料无现成结尾，也应补一句简短收束，保证评论完整。

### 7. 简讯

- 标题概括事件主题；
- 开头通常交代时间 / 事件，不单写过渡句；
- 主体多写亮点、做法、意义 / 影响；
- 结尾从材料或题干找收束句，必要时将前后信息合并形成一句。

### 8. 工作内容

若题干明确只要求“工作事项及相应工作内容”，则：

- **只写主体**；
- 按“工作事项：……；工作内容：……”逐项对应。

### 9. 内容提纲

- 标题：关于 + 主题 + 的谈话 / 指导 / 内容提纲；
- 开头简短交代对象、场景、反馈目的；
- 主体严格按题干要求分层，如“成效—问题—建议”。

### 10. 实用建议 / 提案

若题干只要求“提案案由 + 建议”：

- 不补标题以外的无关格式；
- **案由**可写原因、影响、问题，形成“为什么要提”；
- **建议**分条写可执行对策。

### 11. 编者按

- 不写客套话；
- “编者按：”后直接进入正文；
- 开头来自题干 / 材料，交代刊发背景或人物 / 集体价值；
- 主体多为主体 + 做法 + 影响；
- 材料没有合适结尾时，可自行补一句简短评价 / 号召。

### 12. 工作简报

- 标题：关于 + 主题 + 的 + 文种；标题太长可省“关于”；
- **特殊落款**：单位、日期可放在标题正下方左右位置；
- 开头：“……运行 / 工作情况如下”；
- 主体：“一、总括词。…… 二、总括词。……”；
- 材料有结尾则写，没有可省。

### 13. 案例摘要

- 若题干要求突出做法和意义，主体就是**对策 / 做法 + 意义 / 影响**；
- 字数 ≤400：开头从简，直接进入核心做法与成效；
- 不必把“案例一 / 案例二”机械写成标签，直接提炼共同做法 / 典型内容；
- 结尾：材料有且字数宽裕（如 ≥500）可写；字数紧（如 ≤400）可省。

## 七、与小马哥、白鹭的整合方式

### 1. 三人的功能分工

| 方法 | 在小题 skill 中的主职责 |
|---|---|
| **袁东** | **先找点、先分材料逻辑、先判要素；公文做文种化校验** |
| **小马哥** | 把采分点压成“上位概括词 + 具体内容”的稳定答案结构 |
| **白鹭** | 用题干四要素和“结构随题干变化”处理多要素、多主体、特殊分析题 |

### 2. 默认执行顺序

1. **题干**：先确定问什么、写什么、字数、身份、场景；
2. **袁东层**：宏观 / 中观 / 微观扫描，形成“材料采分点底稿”；
3. **白鹭层**：检查题干结构、要素栏位、逻辑顺序；
4. **小马哥层**：压缩成可上答题纸的“概括词 + 内容”；
5. **袁东复核**：原词是否保留、材料逻辑是否被破坏、公文文种是否漏部件。

### 3. 冲突时的优先级

**题干 > 材料原意与材料逻辑 > 文种目的 > 教师模板 / 口诀。**

任何老师的方法都不能成为脱离题干和材料的扣分标准。

### 4. 什么时候单独生成“袁东版”

默认**不为了凑三版而凑三版**。以下情况才单列：

- 用户明确说“按袁东方法答”；
- 用户要求三位老师对照；
- 公文题属于本库列明的 13 类文种，袁东有明显独立结构；
- 袁东的方法会导致与小马哥 / 白鹭实质不同的要点组织。

否则，把袁东用于“找点 + 复核”即可。

## 八、批改时的袁东专项检查

> **这些是检查维度，不是自动扣分项。** 只有它们导致漏采分点、答非所问、格式错误或挤占有效字数时，才反映到分数。

### 1. 材料逻辑

- 是否把同一话题段落错误拆散；
- 是否把总分 / 分总 / 并列 / 递进关系读反；
- 是否为了“凑三点”破坏材料自身结构。

### 2. 原词与关键词

- 关键动词、对象、结果词是否保留；
- 是否为了追求“高级表达”改掉采分关键词；
- 是否大面积自造材料外概括词。

### 3. 要素匹配

- 问题题有没有写成原因；
- 原因题候选点能否通过“代入法”；
- 对策是否真的是“动词 + 事情”；
- 词句理解是否先做了“就近解释”。

### 4. 公文完成度

逐项核对：

- 题干指定内容是否全部覆盖；
- 标题 / 称谓 / 落款等格式是否与文种和场景匹配；
- 开头、主体、结尾是否围绕文种目的服务；
- 是否出现“模板很完整，但题干让写的内容反而没写”的问题。
