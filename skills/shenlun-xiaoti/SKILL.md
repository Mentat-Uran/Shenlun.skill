# 申论小题

**本 skill 只管小题**（归纳概括／综合分析／对策／公文）。大作文见 `shenlun-dawenti`；
图片输入、真题识别、错题库、导出见 `shenlun-router`。

本 skill 的目标不是把三位老师的口诀全部叠加，而是明确分工：

- **袁东**：先把材料读对、要素找对，公文文种判对；
- **白鹭**：按题干结构拆要素、定答案层级；
- **小马哥**：把采分点压成可直接写上答题卡的稳定结构。

---

## 一、解题流程（强制门控）

> ⛔ **不要只照本文件直接产答案。** 本文件负责流程与门控；三位老师的具体方法在 references 中。

### Step 1：判题型、作答对象与限制

先拆：

1. 题型；
2. 作答对象 / 要素；
3. 给定材料范围；
4. 字数；
5. 身份、场景、文种（如有）。

### Step 2：【门控】先读袁东

读取 `references/yuan-dong-xiaoti-methodology.md`，先做一遍：

- **宏观粗读**：段首、段尾、高频词、关联词、关键词、主体；
- **中观逻辑**：总分、分总、总分总、并列、递进；
- **微观精读**：化大为小 + 目标导向；
- 形成**材料采分点底稿**；
- 规范表达优先保留材料原词原意，故事案例通常跳过；
- 公文题先锁定对应文种及必要部件。

### Step 3：【门控】读白鹭

读取 `references/bai-lu-methodology.md`，用其：

- 题干四要素审题；
- 关键词 / 逻辑阅读；
- “结构随题干变化”的组织方式；
- 多要素、多主体、词句理解等特殊题型处理。

### Step 4：【门控】读小马哥

读取 `references/xiaoma-methodology.md`，用其：

- “问啥答啥，有啥写啥”；
- “大哥 / 小弟”层次判断；
- “上位概括词 + 具体内容”的答题卡结构；
- 对策来源与材料原词保留。

### Step 5：先生成“采分点底稿”，再成文

底稿必须先于参考答案：

- 每个采分点写清：材料依据 → 对应题干要素 → 是否合并；
- 原因题候选点用**代入法**复核；
- 对策题优先级：直接对策 → 问题反推 → 案例启示 → 知识储备兜底；
- 词句理解先做**就近解释**，再补表现 / 原因 / 影响 / 对策等材料要素；
- 公文先按题干内容任务分层，再套文种格式，不得反过来。

### Step 6：生成参考作答

**默认仍保留两种结构性答案**：

1. **小马哥版**：结构稳定、要素融合，偏“概括词 + 具体内容”；
2. **白鹭版**：结构随题干、多要素分栏 / 分层。

两版都必须先通过袁东层的“材料逻辑 + 原词 + 要素”复核。

**袁东版不强制每题都出。** 仅在以下情况单独生成：

- 用户明确要求“按袁东答”；
- 用户要求三位老师对照；
- 公文题属于袁东有明确文种结构的类型；
- 袁东方法会导致与另外两版**实质不同的组织结构**。

若只是换措辞，不得硬凑第三版。

### Step 7：差异对照

至少说明：

1. 各版多踩 / 漏了哪个采分点；
2. 分类 / 分层逻辑差异；
3. 字数效率；
4. 风险；
5. 哪种结构更适合本题的**客观任务特征**。

> 若三位老师在某环节其实一致，必须明确写“此处一致”，不得编造分歧。

## 二、题型判定

| 题干关键词 | 题型 |
|---|---|
| 概括/梳理/总结/提炼/归纳 + 问题/原因/做法/经验/成效/变化/特点 | 归纳概括题 |
| 分析、理解、评析、认识、看法、谈谈为什么 | 综合分析题 |
| 提出/建议/对策/启示 | 对策启示题 |
| 写一份/起草/拟写 + 文种 | 公文写作题 |

### 袁东要素快速定位

- **概括对策**：动词 + 事情；
- **概括问题**：负面 / 消极 / 坏的信息；
- **概括原因**：因果关系 + 代入法；
- **作用 / 影响**：结果、变化、对谁产生什么作用；
- **变化分析**：变化前（多为负面） vs 变化后（多为改善），按方面配对；
- **启示分析**：从案例提炼可迁移做法；
- **词句理解**：就近解释 → 概括开头 → 内容 + 要素 → 材料有总结再写。

## 三、三种方法的结构定位

| | 小马哥 | 白鹭 | 袁东 |
|---|---|---|---|
| 主职责 | 稳定成文 | 题干拆解 / 灵活分层 | 找点 / 材料逻辑 / 公文文种 |
| 典型结构 | 上位概括词 + 具体内容 | 随题干要素分栏 | 宏观—中观—微观扫描后成文 |
| 强项 | 省字、稳定、答题卡友好 | 多要素、多主体、特殊分析题 | 原词保留、逻辑分组、13 类公文专项 |
| 风险 | 概括过度可能损失关键词 | 分栏过细可能吃字数 | 若把文种模板机械化，可能压过题干 |

**冲突优先级：题干 > 材料原意与材料逻辑 > 文种目的 > 教师模板 / 口诀。**

## 四、用户作答评判

**评分 = 采分点覆盖法（子项逐条核对）**：拆子项 → 逐条核对（踩到≥80%满分／40–80%一半／<40%零分）→ 汇总。

### 核心评分规则

- 申论踩点**加分制，不存在倒扣**；编造内容不得分，但不额外倒扣；
- 口语化不单独扣分，但若改掉 / 丢掉采分关键词，则体现在该采分点失分；
- **老师的方法不是评分点**：没按某个老师的模板写，不等于扣分；
- 先判“是否答到采分点”，再谈结构和表达；
- **不做错别字检查**（除非用户明确要求）；表述问题只给规范替换建议。

### 袁东专项复核（非独立扣分项）

逐题检查：

1. 是否破坏材料总分 / 并列 / 递进逻辑；
2. 关键动词、对象、结果词是否保留；
3. 原因题是否通过代入法；
4. 对策是否真的是“动词 + 事情”；
5. 词句理解是否先完成就近解释；
6. 公文是否漏题干指定内容或关键格式部件。

只有这些问题导致**漏采分点、答非所问、格式错误或挤占有效字数**时，才体现在得分上。

**评分必须使用题目实际分值**，不是百分制。完整评分方法与格式模板见 `references/scoring-rules.md`。

作答铁律（字数/句子结构/去水/概括词/自检）见 `references/writing-rules.md`。
手写作答照片：**不因拍照质量（模糊、光线、倾斜）扣分**；字迹与卷面只在无题干模式下按兜底模式评定。

## 五、公文写作专项

公文题必须额外读取 `references/yuan-dong-xiaoti-methodology.md` 的“六大要素 + 13 类公文”部分。

### 通用六要素

1. 标题；
2. 称谓；
3. 开头；
4. 主体；
5. 结尾；
6. 落款。

### 题干优先

- 题干只让写“工作事项 + 工作内容” → 只写主体；
- 题干只让写“案由 + 建议” → 只完成这两部分；
- 题干要求“成效 + 问题 + 建议” → 主体按三层组织；
- 不得为了格式完整擅自添加题干不需要的部分。

### 袁东 13 类专项

发言提纲、宣传稿、汇报提纲、调研报告、工作建议、短评、简讯、工作内容、内容提纲、实用建议/提案、编者按、工作简报、案例摘要。

遇到上述文种，优先按该文种专项规则复核标题、开头、主体、结尾和落款。

## 六、反馈输出

**默认用精简格式**；用户说“展开”/“详细”才切换详细格式。格式模板见 `references/scoring-rules.md`。

**输出顺序**（改进建议优先，不做空泛诊断）：

1. 必须补的失分点（2-3 个，各附“影响哪个采分点 + 怎么改”）；
2. 材料定位 / 逻辑问题（若有：具体指出总分、并列、递进、就近解释或代入法哪一步错）；
3. 表述升级（口语化 → 申论规范表述，见 `../shared/references/expression-upgrade-rules.md`）；
4. 结构调整（是否该合并 / 分栏 / 换顺序）；
5. 优化示范（挑 1-2 句改写对比）。

成语、名言只在确有用处时补充，不为“高级感”占用小题字数。
